### 二、字段（Field）配置

1. 区分了 t-form-item、内容组件
2. 顶层的是 t-form-item 的，props 中的是内容组件的

```javascript
{
  // ========== 基础配置 ==========
  key: 'fieldName',             // ✅ 必需 - 字段唯一标识
  label: '字段标签',             // ✅ 必需 - 字段显示标签
  type: 'input',                 // ✅ 必需 - 字段类型（见下方支持的类型）
  
  // ========== 字段属性 ==========
  placeholder: '请输入...',     // 占位符文本
  value: '默认值',               // 默认值（也可以在初始化时设置）
  visible: true,                 // 是否可见（true/false），false 时字段会隐藏
  disabled: false,               // 是否禁用（true/false），true 时字段会禁用
  help: '帮助文本',              // 帮助信息（支持模板变量 {{value}}）
  
  // ========== 校验规则 ==========
  rules: [                       // 校验规则数组
    { 
      required: true,            // 是否必填
      message: '不能为空',        // 错误提示（如果不提供会自动生成）
      min: 3,                    // 最小长度
      max: 20,                   // 最大长度
      pattern: /regex/,         // 正则表达式
      validator: (value) => {   // 自定义校验函数
        // 返回 true 或错误消息字符串
        return true; // 或 '错误消息'
      }
    }
  ],
  
  // ========== 组件属性 ==========
  props: {                       // 传递给字段组件的所有属性
    // 组件特定的属性（如 type='password'、min、max、step 等）
    type: 'password',            // input 组件的 type 属性
    class: 'custom-class',       // CSS 类名（通过 props 传递）
    style: { width: '200px' },   // 样式对象（通过 props 传递）
    clearable: true,             // 是否显示清除按钮
    // ... 其他 TDesign 组件属性
  },
  
  // ========== 选项数据（用于 select/radio/checkbox） ==========
  options: [                     // 静态选项数组
    { 
      label: '选项1',            // 显示文本
      value: 'option1',          // 选项值
      disabled: false,           // 是否禁用该选项
      props: {                   // 选项的额外属性（传递给选项组件）
        // ... 选项组件特定属性
      }
    }
    // 注意：可以通过联动动态设置选项（使用 context.setFieldOptions()）
  ],
  
  // ========== 装饰器配置 ==========
  topDecorator: { ... },         // 上置装饰器配置（见下方装饰器配置）
  beforeDecorator: { ... },      // 前置装饰器配置
  afterDecorator: { ... },       // 后置装饰器配置
  bottomDecorator: { ... },      // 下置装饰器配置
  
  // ========== 联动配置 ==========
  linkage: [                     // 联动逻辑数组
    {
      watchField: 'otherField',  // ✅ 必需 - 监听的字段 key
      action: async (value, context) => {
        // ✅ 必需 - 联动执行函数
        // value: 被监听字段的新值
        // context: 表单操作上下文（见下方 Context API）
      }
    }
  ]
}
```

### 三、装饰器配置

#### 1. text/html 类型装饰器

```javascript
{
  type: 'text',                   // 或 'html' - ✅ 必需 - 装饰器类型
  value: '装饰器内容',             // ✅ 必需 - 显示内容（支持模板变量 {{value}}）
  
  // ========== 样式配置（独立字段，优先级高于 props） ==========
  className: 'decorator-class',  // CSS 类名（独立字段，会覆盖 props.class）
  style: {                        // 样式对象（独立字段，会覆盖 props.style）
    color: '#1890ff',
    fontWeight: 'bold'
  },
  
  // ========== 其他属性 ==========
  props: {                         // 额外的 HTML 属性（可选，会被 className/style 覆盖）
    id: 'decorator-id',
    // ... 其他 HTML 属性
  },
  
  // ========== 联动配置（可选） ==========
  linkage: [                       // 装饰器联动逻辑（同字段联动）
    {
      watchField: 'fieldKey',      // 监听的字段 key
      action: async (value, context) => {
        // 联动逻辑（可以通过 context 更新装饰器或其他字段）
      }
    }
  ]
}
```

#### 2. 组件类型装饰器

```javascript
{
  type: 'TButton',                 // ✅ 必需 - 组件类型（TDesign 组件名或自定义组件）
  
  // ========== 组件属性（统一通过 props 传递） ==========
  props: {                         // ✅ 必需 - 组件属性对象
    theme: 'primary',              // 组件特定属性
    size: 'small',
    variant: 'outline',
    class: 'decorator-class',      // CSS 类名（通过 props 传递）
    style: { marginLeft: '8px' },  // 样式对象（通过 props 传递）
    // ... 其他组件属性
  },
  
  // ========== 联动配置（可选） ==========
  linkage: [                       // 装饰器联动逻辑
    {
      watchField: 'fieldKey',      // 监听的字段 key
      action: async (value, context) => {
        // 可以通过 context.updateDecoratorProps() 更新装饰器属性
        context.updateDecoratorProps('fieldKey', 'after', {
          theme: 'success'
        });
      }
    }
  ]
}
```

注意：组件类型装饰器不支持独立的 `className` 和 `style` 字段，必须通过 `props.class` 和 `props.style` 传递。

### 五、联动 Context API

在联动 `action` 函数中可以使用的上下文方法：

```javascript
{
  // ========== 表单数据 ==========
  formData: {},                   // 当前表单数据对象（响应式）
  
  // ========== 字段显示/隐藏 ==========
  showField: (fieldKey) => {},    // 显示字段（从隐藏中恢复）
  hideField: (fieldKey) => {},    // 隐藏字段
  
  // ========== 字段启用/禁用 ==========
  enableField: (fieldKey) => {},  // 启用字段（从禁用中恢复）
  disableField: (fieldKey) => {}, // 禁用字段
  
  // ========== 字段值操作 ==========
  setFieldValue: (fieldKey, value) => {}, // 设置字段值
  
  // ========== 选项操作 ==========
  setFieldOptions: (fieldKey, options) => {}, // 动态设置字段选项（覆盖静态 options）
  
  // ========== API 调用 ==========
  callApi: async (apiConfig, params) => {
    // apiConfig: { url, method, headers, transform }
    // params: 请求参数
    // 返回: API 响应数据
  },
  
  // ========== 装饰器操作（仅组件类型装饰器） ==========
  updateDecoratorProps: (fieldKey, position, props) => {}, // 更新装饰器属性
  showDecorator: (fieldKey, position) => {},              // 显示装饰器
  hideDecorator: (fieldKey, position) => {},              // 隐藏装饰器
}
```

装饰器位置（position）可选值：
- `'top'` - 上置装饰器
- `'before'` - 前置装饰器
- `'after'` - 后置装饰器
- `'bottom'` - 下置装饰器

### 六、模板变量支持

在 `help` 和装饰器的 `value` 中支持模板变量：

- `{{value}}` - 当前字段的值
  - 在 `help` 中：如果值为空，显示 "未选择"
  - 在装饰器 `value` 中：如果值为空，显示空字符串

### 七、配置优先级总结

#### 装饰器样式优先级：
- text/html 装饰器：`className/style` > `props.class/props.style`
- 组件装饰器：统一通过 `props` 传递（包括 `props.class` 和 `props.style`）

#### 字段属性优先级：
- 显式绑定（`:placeholder`、`:disabled`、`:loading`）> `field.props` 中的同名属性
