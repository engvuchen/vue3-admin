## cls 属性案例

参考 https://tencent.github.io/WeComponents/#/doc/principle/cls 中的内容；

cls 顶层属性一共有：

```js
{
    id: '',
    name: '',
    label: '',
    comopnent: '',
    value: '',
    valueFilterName: '' // 忽略

    attributes: {}, 
    events: {}, // 忽略
    items: {},
    validity: [],
    extra: {}
}
```

attributes 定义：

```js
{
    class: '',
    style: '',
    placeholder: '',
    hide: false,
    disabled: true,
    readonly: false,
    sortable: '',
    searchable: false,
    resetable: false,
    multiple: true
    // 其他是组件自定义选项
}
```

一个简单的 cls 配置结构：

```js
{
    component: 'input',
    name: 'lottery',
    label: '抽奖名',
    value: '',
    attributes: {
        disabled: false,
        hide: false
    },
    events: {
        changeEventName: ''
    }
}
```

## 重写实现

- 仅支持 CLS 规范：顶层使用 `attributes`/`items`，字段使用 `name`/`label`/`component`/`attributes`/`validity`/`items`/`decoration`/`linkage`。
- 旧版 API 废弃：如顶层直接放 `layout/labelWidth/.../fields`、字段直接放 `type/placeholder/value/visible/disabled/help/rules/props/options/...` 均不再解析。
- 迁移：
  - 顶层：将 `layout/labelWidth/labelAlign/colon/class/style/showSubmit/showReset/submitText/resetText` 移入 `attributes`。
  - 字段：`key/type` → `name/component`；通用属性统一移入 `attributes`；`rules` → `validity`；`options` → `items`；装饰器合并到 `decoration`，用 `attributes.placement` 指位。
- 废弃字段：`valueFilterName`、旧的顶层 `fields`、字段直挂的 `props/options/rules` 等。

### 一、表单级别配置（顶层 config）

旧配置：

```javascript
{  
    // ========== 布局配置 ==========
    layout: 'vertical',           // 表单布局：'vertical' | 'inline' | 'horizontal'（默认：'vertical'）
    labelWidth: '120px',          // 标签宽度（默认：'120px'）
    labelAlign: 'right',          // 标签对齐方式：'left' | 'right' | 'top'（默认：'right'）
    colon: true,                  // 是否显示冒号（默认：true）

    // ========== 样式配置 ==========
    class: '',                // 表单自定义类名（默认：''）
    style: {},                    // 表单自定义样式对象（默认：{}）

    // ========== 按钮配置 ==========
    showSubmit: true,             // 是否显示提交按钮（默认：true）
    showReset: true,              // 是否显示重置按钮（默认：true）
    submitText: '提交',            // 提交按钮文本（默认：'提交'）
    resetText: '重置',             // 重置按钮文本（默认：'重置'）
    // ========== 字段配置 ==========
    fields: [],                   // 表单字段配置数组（默认：[]）
}
```

改为：

```js
{
    attributes: {
        // ========== 布局配置 ==========
        layout: 'vertical',           // 表单布局：'vertical' | 'inline' | 'horizontal'（默认：'vertical'）
        labelWidth: '120px',          // 标签宽度（默认：'120px'）
        labelAlign: 'right',          // 标签对齐方式：'left' | 'right' | 'top'（默认：'right'）
        colon: true,                  // 是否显示冒号（默认：true）
        
        // ========== 样式配置 ==========
        class: '',                // 表单自定义类名（默认：''）
        style: {},                    // 表单自定义样式对象（默认：{}）
        
        // ========== 按钮配置 ==========
        showSubmit: true,             // 是否显示提交按钮（默认：true）
        showReset: true,              // 是否显示重置按钮（默认：true）
        submitText: '提交',            // 提交按钮文本（默认：'提交'）
        resetText: '重置',             // 重置按钮文本（默认：'重置'）
    },
    items: [
        // ========== 字段配置 ==========
    ]
}
```

  topDecorator: { ... },         // 上置装饰器配置（见下方装饰器配置）
  // 或
  topDecorator: [{ ... }, { ... }], // 支持数组形式，同一方向可以放置多个装饰器
  beforeDecorator: { ... },      // 前置装饰器配置（支持单个或数组）
